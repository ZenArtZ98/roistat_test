# AmoCRM Webhook Sender

Проект — простая веб-форма для отправки заявок в AmoCRM через API.  
Форма собирает имя, email, телефон, цену, и фиксирует, провёл ли пользователь на сайте больше 30 секунд.

### Запуск проекта

```bash
php -S localhost:8000 -t public
```

### 4. Открыть в браузере

```
http://localhost:8000
```

## ⚙ Настройка

Перед запуском необходимо:

- В `public/index.php` указать **актуальный access_token AmoCRM**
- Убедиться, что поле `field_id` (для времени) соответствует ID булевого поля в AmoCRM

## 📋 Особенности

- Валидация номера телефона на стороне клиента (`+7...`)
- Логирование успешных и неуспешных запросов
- Отображение результата без перезагрузки страницы
